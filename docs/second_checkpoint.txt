Stage 2 Spec: Week 1.5 — Ed25519 Signing
What Week 1 proved: The receipt chain is real, deterministic, and tamper-evident via hash validation. What Week 1.5 proves: The receipt chain is attributable — a specific keypair produced it, and any runtime can verify this without trusting the producer.

Scope (tight, nothing else)
Three things and only three things:

1. identity.py — Keypair management Generate, persist, and load an Ed25519 keypair. Store as two files: identity.pub and identity.key (the latter chmod 600). Never embed the private key in a capsule or receipt. The keypair is the agent's identity — lose it and provenance is broken.

2. Detached signatures on the receipt log On every COMMIT, take the current log_chain_head hash and sign it with the private key. Append a "sig" field to that receipt: { ..., "sig": "<base64_ed25519_sig>", "pub": "<base64_pubkey>" }. Do not sign the full capsule blob — sign the chain head. This way the log is self-validating even if the capsule is lost.

3. Signature verification on replay During replay_log, for every receipt that has a "sig" field: verify the signature against "pub" and the log_chain_head at that point. If verification fails, halt with a clear error — same pattern as the chain break you already have.

What Stage 2 does NOT touch
No capsule-level signing yet. No TTL. No cross-runtime import. No network. Those are Week 2. Scope creep killed more projects than bad code.

"""
cc/identity.py — Ed25519 identity layer (PyNaCl).

Public API — exactly three functions, nothing else is exported:

    generate_keypair() -> tuple[str, str]
        Generate a new keypair, write to disk, return (sk_b64, vk_b64).

    sign_payload(payload_bytes: bytes) -> str
        Load private key from KEY_FILE, sign payload, return base64 sig.

    verify_payload(payload_bytes: bytes, sig_b64: str, vk_b64: str) -> None
        Verify signature against public key.
        Raises nacl.exceptions.BadSignatureError if invalid.

Key files
---------
KEY_FILE  cc_identity.key   chmod 600 — private key + verify key, JSON
PUB_FILE  cc_identity.pub   public key only, JSON

Design decisions
----------------
- sign_payload loads from disk on every call.
  No in-memory key caching in Stage 2 — the added complexity isn't earned yet.
- verify_payload is purely a validator. It raises on failure.
  Callers are responsible for catching and handling the exception.
- Both files store base64-encoded raw Ed25519 bytes (32 bytes each).
  No PEM, no DER, no certificate chains. Local-first means minimal format.
"""

import base64
import json
import os
import stat

import nacl.exceptions
import nacl.signing

KEY_FILE = "cc_identity.key"
PUB_FILE = "cc_identity.pub"


def generate_keypair() -> tuple[str, str]:
    """
    Generate a fresh Ed25519 keypair and persist it to disk.

    Writes:
        KEY_FILE  — JSON: {"sk": "<base64>", "vk": "<base64>"}  chmod 600
        PUB_FILE  — JSON: {"vk": "<base64>"}

    Returns:
        (sk_b64, vk_b64) — base64-encoded signing key and verify key.

    Overwrites any existing key files without warning.
    Back up KEY_FILE before calling on a live agent.
    """
    signing_key = nacl.signing.SigningKey.generate()
    verify_key = signing_key.verify_key

    sk_b64 = base64.b64encode(bytes(signing_key)).decode()
    vk_b64 = base64.b64encode(bytes(verify_key)).decode()

    # write private key file
    with open(KEY_FILE, "w") as f:
        json.dump({"sk": sk_b64, "vk": vk_b64}, f)

    # lock it down — owner read/write only, no group, no world
    os.chmod(KEY_FILE, stat.S_IRUSR | stat.S_IWUSR)

    # write public key file (safe to share)
    with open(PUB_FILE, "w") as f:
        json.dump({"vk": vk_b64}, f)

    return sk_b64, vk_b64


def sign_payload(payload_bytes: bytes) -> str:
    """
    Sign `payload_bytes` with the private key stored in KEY_FILE.

    Returns:
        base64-encoded Ed25519 signature (64 bytes raw → 88 base64 chars).

    Raises:
        FileNotFoundError  if KEY_FILE does not exist.
        KeyError           if KEY_FILE is malformed (missing 'sk' field).
    """
    with open(KEY_FILE) as f:
        data = json.load(f)

    signing_key = nacl.signing.SigningKey(base64.b64decode(data["sk"]))
    sig_bytes = signing_key.sign(payload_bytes).signature
    return base64.b64encode(sig_bytes).decode()


def verify_payload(payload_bytes: bytes, sig_b64: str, vk_b64: str) -> None:
    """
    Verify `sig_b64` over `payload_bytes` using `vk_b64`.

    Returns:
        None on success.

    Raises:
        nacl.exceptions.BadSignatureError  if the signature is invalid.
        Any base64 / format exception propagates as-is.

    This function is intentionally side-effect free — it does not touch
    the file system. The verify key travels with the capsule.
    """
    verify_key = nacl.signing.VerifyKey(base64.b64decode(vk_b64))
    verify_key.verify(payload_bytes, base64.b64decode(sig_b64))
